# E2E Requirements & Testability Report

This document outlines the functional requirements of the Frontend application and their E2E testability status.

## Legend

- ✅ **Covered**: Test exists and passes.
- ⚠️ **Partial**: Some scenarios covered, others missing.
- ⬜ **Missing**: No E2E test implemented.
- ⏭️ **Skipped**: Hard to test E2E (e.g., visual webgl correctness) or low priority.
