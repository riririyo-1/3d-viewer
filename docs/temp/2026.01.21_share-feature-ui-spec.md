# 共有機能 UI 仕様書 (2026.01.21版)

## 概要

以下の2つの画面・UIコンポーネントを実装します。

1. 既存 Collection 画面 (`/collection`) への共有ボタン追加
2. 共有管理画面 (`/share`) の新規作成

## 技術選定 (Frontend)

本プロジェクトの既存スタックに合わせ、以下のライブラリ・コンポーネントを使用します。

- UI Framework: Next.js (App Router), Tailwind CSS
- Component Library: shadcn/ui
  - Popover: 共有設定の固定ポップアップ表示に使用 (Collection画面)
  - Dialog: オブジェクト削除確認等に使用
  - Table: 共有リンク一覧に使用
  - Toast (Sonner): リンクコピー時のフィードバックに使用
- Icons: `lucide-react` (Share2, Copy, Trash2, Edit, AlertCircle 等)
- Clipboard: `navigator.clipboard.writeText` または標準的な実装

---

## 1. Collection 画面 (`/collection`) UI 仕様

オブジェクト一覧（カード表示/リスト表示）から直接共有リンクを生成・確認できるUIを提供します。

### 1-1. 共有ボタンの配置

- カードビュー (`AssetCard`): カード下部のアクションエリア（またはメニュー内）に「共有アイコン (Share2)」を配置。
- リストビュー (`AssetTable`): 操作列に「共有ボタン」またはアイコンを配置。

### 1-2. 共有設定ポップオーバー (Popover)

「共有」ボタンをクリックすると、ページ遷移やモーダル展開を行わず、ボタンの近くに設定用ポップオーバー (`PopoverContent`) を表示します。
実装にあたっては、状態Aと状態Bを同じポップオーバー内で切り替える形とし、ポップオーバーのサイズ変動を抑制したクリーンな設計としてください。

#### 状態A: 未共有の場合

1. 設定項目表示:
   - 有効期限: セレクトボックス (なし / 7日 / 30日)
2. アクション:
   - 「共有リンクを生成」ボタン (Primary)
   - ボタン押下後、APIリクエストを行い、成功したら状態Bへ移行。

#### 状態B: 共有済みの場合

既に共有リンクが存在する場合、または生成完了後はこの表示になります。

1. リンク表示エリア:
   - 生成されたURL (Readonly input)
   - 「コピー」ボタン (Icon: Copy)
     - クリック時に「リンクをコピーしました」とToast表示
2. 設定情報 (Readonly):
   - 現在の有効期限を簡易表示
3. アクション:
   - 「設定を変更」リンク/ボタン (状態Aのような編集モードへ)
   - 「共有を解除 (削除)」ボタン (Destructive)

## 2. 共有管理画面 (`/share`) UI 仕様

全共有リンクを一元管理する独立したページです。本画面は**作成済みのリンク管理専用**とし、新規作成機能は持ちません（作成はCollection画面から行います）。

### 2-1. 画面構成

- ヘッダー:
  - タイトル: "共有管理"
- 共有リンク一覧 (Table):
  - カラム構成:
    - オブジェクト名: サムネイル + アセット名
    - アクセス数: 現在の閲覧数
    - 有効期限: 日時表示 (期限切れは赤字またはバッジ表示)
    - 共有リンク: URL + コピーボタン
    - 作成日: YYYY/MM/DD
    - 操作: 編集 / 削除メニュー
  - ページネーション: 1ページあたりの表示件数を考慮 (例: 20件)

## 3. 実装上の考慮事項 (Frontend)

### 3-1. 必要な shadcn コンポーネント

以下のコンポーネントを使用します。

- popover
- dialog
- toast
- table
- tooltip
- scroll-area

### 3-2. ローディング状態

- リンク生成APIコール中は、ボタンをLoading状態 (`disabled` + Spinner) にする。
- 一覧取得中はスケルトンローダー (`Skeleton`) を表示し、UXを損なわないようにする。
