# 共有機能 要件書

## 概要

3D オブジェクトを外部ユーザーと共有するための機能を実装する。
ホーム画面の機能一覧に「共有」カードを新規追加し、オブジェクトをリンク形式で他者と共有できるようにする。

## 機能要件

### 1. ホーム画面への共有カード追加

- ホーム画面（`/`）の機能カードに「Share」カードを追加する
- カードをクリックすると共有管理画面（`/share`）に遷移する

### 2. 共有管理画面（`/share`）

#### 2.1 共有リンク一覧

- 作成済みの共有リンク一覧を表示する
- 各リンクに対して以下の情報を表示する
  - 共有対象オブジェクト名
  - 共有リンク URL
  - 作成日時
  - 有効期限
  - パスワード保護の有無
- リンクのコピー、情報編集、削除が可能

#### 2.2 共有リンク作成

- 「新規共有リンク作成」ボタンを配置する
- クリックすると共有リンク作成ダイアログを表示する
- 既存のcollection一覧が表形式で表示される。
  - collection名
  - 拡張子
  - サイズ
  - 更新日時
- 共有するオブジェクトを選択する
- 

### 3. 共有リンク作成ダイアログ

#### 3.1 オブジェクト選択

- ユーザーが所有するアセット一覧から共有対象を選択する
- サムネイル付きのリスト形式で表示する

#### 3.2 共有設定オプション

| 設定項目       | 説明                                       | デフォルト値 |
| :------------- | :----------------------------------------- | :----------- |
| 有効期限       | リンクの有効期限（なし/1日/7日/30日/カスタム） | なし         |
| パスワード保護 | 共有リンクにパスワードを設定               | OFF          |
| 閲覧回数制限   | 最大閲覧回数を設定（なし/1回/10回/100回）  | なし         |

#### 3.3 共有リンク生成

- 「リンクを生成」ボタンをクリックすると共有リンクを生成する
- 生成されたリンクをワンクリックでコピーできるようにする
- リンク形式: `https://{domain}/shared/{shareId}`

### 4. 共有ビューア画面（`/shared/[shareId]`）

#### 4.1 認証不要での閲覧

- 共有リンクを開いた外部ユーザーは、ログイン不要でオブジェクトを閲覧できる
- 3D ビューア機能（回転、ズーム、パン）を提供する

#### 4.2 パスワード保護されたリンク

- パスワードが設定されている場合、閲覧前にパスワード入力画面を表示する
- 正しいパスワードを入力するとオブジェクトを閲覧できる

#### 4.3 ダウンロード機能

- 「ダウンロード」ボタンを配置する
- 未ログインユーザーがクリックした場合、ログイン/登録画面に誘導する
- ログイン済みユーザーのみダウンロード可能

#### 4.4 エラーハンドリング

- リンクが無効（期限切れ、削除済み、閲覧回数超過）の場合、エラーメッセージを表示する
- エラーメッセージ例:
  - 「このリンクは有効期限が切れています」
  - 「このリンクは既に削除されています」
  - 「このリンクの閲覧回数が上限に達しました」

### 5. ビューア画面からの共有

- 既存のビューア画面（`/viewer/[id]`）に「共有」ボタンを追加する
- クリックすると共有リンク作成ダイアログを表示する（対象オブジェクトは自動選択）

## 非機能要件

### セキュリティ

- 共有リンクの shareId は UUID v4 を使用し、推測不可能にする
- パスワードはハッシュ化して保存する（bcrypt 使用）
- 閲覧回数・有効期限のチェックはサーバーサイドで実施する

### パフォーマンス

- 共有リンク一覧は最大 100 件まで表示する
- ページネーションを実装する

## データベース設計

### ShareLink テーブル

```prisma
model ShareLink {
  id             String    @id @default(uuid()) @db.Uuid
  userId         String    @map("user_id") @db.Uuid
  assetId        String    @map("asset_id") @db.Uuid
  shareId        String    @unique @map("share_id") @db.VarChar(36)
  password       String?   @db.VarChar(255)    // bcrypt ハッシュ
  expiresAt      DateTime? @map("expires_at")
  maxViews       Int?      @map("max_views")
  viewCount      Int       @default(0) @map("view_count")
  createdAt      DateTime  @default(now()) @map("created_at")
  updatedAt      DateTime  @updatedAt @map("updated_at")

  user  User  @relation(fields: [userId], references: [id], onDelete: Cascade)
  asset Asset @relation(fields: [assetId], references: [id], onDelete: Cascade)

  @@index([userId], name: "idx_share_links_user_id")
  @@index([shareId], name: "idx_share_links_share_id")
  @@index([expiresAt], name: "idx_share_links_expires_at")
  @@map("share_links")
}
```

## 実装優先度

1. **Phase 1（MVP）**
   - 共有リンク作成・一覧表示
   - 共有ビューア画面（パスワード保護なし）
   - ダウンロード制限（ログイン必須）

2. **Phase 2**
   - パスワード保護機能
   - 有効期限設定
   - 閲覧回数制限

3. **Phase 3**
   - ビューア画面からの共有
   - ホーム画面への共有カード追加

## 技術選定

### 1. 共有 ID 生成方式の比較

| 項目 | NanoID | UUID v4 | Sqids (旧 Hashids) |
| :--- | :--- | :--- | :--- |
| **長さ** | 12〜21 文字（設定可能） | 36 文字（ハイフン含む） | 可変（短い） |
| **ランダムビット** | 126 ビット（21 文字時） | 122 ビット | 決定論的（入力依存） |
| **衝突確率** | 非常に低い | 非常に低い | 衝突なし（決定論的） |
| **URL フレンドリー** | ◎（A-Za-z0-9_- のみ） | △（ハイフンあり） | ◎ |
| **サイズ（バンドル）** | 130 bytes | 423 bytes | 約 1KB |
| **npm ダウンロード数** | 6,700 万/週 | - | 27 万/週 |
| **デコード可能性** | 不可 | 不可 | 可能（元の数値に戻せる） |
| **セキュリティ** | 暗号論的乱数使用 | 暗号論的乱数使用 | 難読化のみ（暗号ではない） |
| **GCP 互換性** | ◎ | ◎ | ◎ |

### 2. ファイルアクセス方式の比較

| 項目 | Signed URL（署名付き URL） | アプリ経由プロキシ | 公開 URL + トークン |
| :--- | :--- | :--- | :--- |
| **概要** | ストレージが一時的な署名付き URL を発行 | アプリサーバーがファイルを中継 | 公開バケット + アプリ側でトークン検証 |
| **セキュリティ** | ◎（有効期限・権限を細かく制御） | ○（アプリ側で完全制御） | △（URL 漏洩リスク） |
| **パフォーマンス** | ◎（CDN 併用可、サーバー負荷なし） | △（サーバー負荷大） | ◎ |
| **GCP 対応** | ◎（Cloud Storage Signed URL） | ○ | ○ |
| **MinIO 対応** | ◎（S3 互換 Presigned URL） | ○ | ○ |
| **有効期限設定** | 最大 7 日間 | アプリ側で自由 | アプリ側で自由 |
| **大容量ファイル** | ◎（5GB まで直接転送） | △（サーバーメモリ制約） | ◎ |
| **実装複雑度** | 中 | 低 | 低 |

### 3. 推奨構成

#### 共有 ID 生成: **NanoID（推奨）**

**選定理由:**

- URL フレンドリーで短い ID（12 文字程度で十分な衝突耐性）
- 暗号論的に安全な乱数を使用
- 軽量（130 bytes）でバンドルサイズへの影響が最小
- デコード不可のため、DB の内部 ID を推測されない
- TypeScript 対応が充実

```typescript
import { nanoid } from 'nanoid';

// 12文字の共有ID生成（約35年間、毎時1000件生成で1%の衝突確率）
const shareId = nanoid(12);
// 例: "V1StGXR8_Z5j"
```

#### ファイルアクセス: **Signed URL（推奨）**

**選定理由:**

- サーバーリソースを使用せず、ストレージから直接配信
- GCP Cloud Storage / MinIO 両方で同一パターンで実装可能
- 有効期限を短く設定することでセキュリティを確保
- CDN（Cloud CDN）との併用で高速配信が可能

**GCP 移行時の考慮事項:**

| 現在（MinIO） | GCP 移行後 |
| :--- | :--- |
| `@aws-sdk/s3-request-presigner` | `@google-cloud/storage` |
| `getSignedUrl()` | `file.getSignedUrl()` |
| HMAC 署名 | IAM Signed URL（キーレス署名推奨） |

### 5. 実装例

#### NanoID による共有 ID 生成

```typescript
// server/src/shares/shares.service.ts
import { nanoid } from 'nanoid';

@Injectable()
export class SharesService {
  async createShareLink(userId: string, dto: CreateShareDto) {
    const shareId = nanoid(12); // 12文字の一意ID

    return this.prisma.shareLink.create({
      data: {
        userId,
        assetId: dto.assetId,
        shareId,
        password: dto.password ? await bcrypt.hash(dto.password, 10) : null,
        expiresAt: dto.expiresAt,
        maxViews: dto.maxViews,
      },
    });
  }
}
```

#### Signed URL によるファイル配信

```typescript
// server/src/shares/shares.service.ts
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';
import { GetObjectCommand } from '@aws-sdk/client-s3';

async getSharedAssetUrl(shareId: string): Promise<string> {
  const shareLink = await this.validateShareLink(shareId);

  const command = new GetObjectCommand({
    Bucket: this.configService.get('MINIO_BUCKET_NAME'),
    Key: shareLink.asset.storagePath,
  });

  // 15分間有効な署名付きURLを生成
  return getSignedUrl(this.s3Client, command, { expiresIn: 900 });
}
```

#### GCP 移行時のコード変更

```typescript
// GCP Cloud Storage 版
import { Storage } from '@google-cloud/storage';

const storage = new Storage();

async getSharedAssetUrl(shareId: string): Promise<string> {
  const shareLink = await this.validateShareLink(shareId);

  const [signedUrl] = await storage
    .bucket(this.configService.get('GCS_BUCKET_NAME'))
    .file(shareLink.asset.storagePath)
    .getSignedUrl({
      version: 'v4',
      action: 'read',
      expires: Date.now() + 15 * 60 * 1000, // 15分
    });

  return signedUrl;
}
```

### 7. セキュリティベストプラクティス

| 項目 | 推奨設定 |
| :--- | :--- |
| Signed URL 有効期限 | 15 分（閲覧用）、5 分（ダウンロード用） |
| 共有 ID 長 | 12 文字（NanoID） |
| パスワードハッシュ | bcrypt（ソルトラウンド: 10） |
| 閲覧回数チェック | サーバーサイドで atomic 更新 |
| HTTPS 必須 | 本番環境では必須 |
